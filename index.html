Snake & Ladder

A real-time browser game built around WebSockets, authoritative backend game state, multiplayer matchmaking and single-player gameplay against a computer.

React Tailwind CSS Node.js WebSockets Real-time state
View on GitHub ↗

How it works

01

Multiplayer matchmaking

Players connect through WebSockets. When no opponent is available, the connection enters a waiting list. A second player triggers automatic matchmaking and creates a live game room.

02

Backend-controlled gameplay

The backend owns the game state, player positions, turns, dice rolls, move validation and match results. The frontend renders the state rather than independently calculating it.

03

Play against the computer

Single-player games use a dedicated game room. After the player's move, the backend waits briefly, performs the computer's move, updates the room and continues the cycle.

System architecture

Frontend React + Tailwind
Transport WebSocket
Backend Node.js + ws
State In-memory game rooms

Real-time events

WAITING GAME-STARTED MOVE INVALID-MOVE WON LOST ERROR

Player actions are sent to the backend, which validates the request, updates the game room and broadcasts the resulting state.
